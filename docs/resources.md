# Official resources and further learning

Use the manual corresponding to your installed package version. This page links
to external documentation; it does not redistribute those works.

## Core system

- [LaTeX Project documentation](https://www.latex-project.org/help/documentation/):
  authoritative background and learning resources.
- [TeX Live](https://www.tug.org/texlive/): a cross-platform TeX distribution.
- [MiKTeX](https://miktex.org/): another widely used TeX distribution.
- [CTAN](https://ctan.org/): package descriptions, licenses, and manuals.
- [latexmk on CTAN](https://ctan.org/pkg/latexmk): automated compilation.

## Online editing with Overleaf

[Overleaf](https://www.overleaf.com/) combines a browser-based source editor,
online LaTeX compilation, and a PDF preview. It is an alternative to installing
a TeX distribution locally, not a different document format: you still write
LaTeX and manage the source files used to produce your PDF.

Start with this platform's [Overleaf walkthrough](getting-started.md#in-overleaf),
then consult the official [first-project guide](https://docs.overleaf.com/getting-started/your-first-project)
and [compilation guide](https://docs.overleaf.com/getting-started/recompiling-your-project).
Check current sharing limits and data policies before starting a collaborative
or confidential project.

## Writing and mathematics

- [amsmath](https://ctan.org/pkg/amsmath): displayed and aligned mathematics.
- [siunitx](https://ctan.org/pkg/siunitx): consistent quantities and units.
- [booktabs](https://ctan.org/pkg/booktabs): publication-quality table rules.
- [BibLaTeX](https://ctan.org/pkg/biblatex) and
  [Biber](https://ctan.org/pkg/biber): bibliography formatting and processing.
- [LaTeX tagging project](https://latex3.github.io/tagging-project/):
  current work and guidance for tagged PDFs.

## Graphics and presentations

- [PGF/TikZ](https://ctan.org/pkg/pgf): programmatic vector graphics.
- [PGFPlots](https://ctan.org/pkg/pgfplots): quantitative plots.
- [Beamer](https://ctan.org/pkg/beamer): presentation documents.

## Website and community tooling

- [MkDocs](https://www.mkdocs.org/): Markdown documentation builds.
- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/):
  navigation, themes, search, and code-copy features.
- [MathJax](https://docs.mathjax.org/): accessible mathematical web rendering.
- [GitHub Pages documentation](https://docs.github.com/en/pages):
  hosting and deployment behavior.
