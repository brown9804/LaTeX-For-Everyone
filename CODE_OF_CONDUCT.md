# Community code of conduct

This is a learning community. People with different backgrounds and levels of
experience should be able to ask questions, share work, and receive useful
feedback.

## Expected conduct

- Be respectful and patient, especially with beginners.
- Critique technical claims and examples, not the person who submitted them.
- Explain corrections clearly and acknowledge uncertainty.
- Respect privacy, authorship, attribution, and copyright.
- Keep discussions relevant and make room for different perspectives.

Harassment, threats, discriminatory attacks, deliberate humiliation, disclosure
of private information, and repeated disruptive behavior are not acceptable.

## Reporting and response

For a public conduct problem, use GitHub's reporting controls or flag the
specific issue or pull request for a repository maintainer. Do not publish
private evidence or personal information in a public issue.
GitHub's abuse reporting tools are available when private escalation is needed;
this repository does not currently advertise a separate private reporting inbox.

Maintainers may edit or remove inappropriate contributions, close disruptive
threads, or restrict participation. Responses should take context and severity
into account. Technical disagreement alone is not a conduct violation.

This policy applies to interactions in this repository and its associated
project spaces. It does not replace GitHub's own terms and community policies.
